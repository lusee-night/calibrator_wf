These weights were created using `create_weights.ipynb` in calibrator_wf.

We have the following weights:

0 - alt waveform, main part only
1 - alt waveform, full range, >0.5 only
2 - alt waveform, full range, >0.2 only
3 - norm waveform, full range
4 - norm waveform, around bright part
5 - norm waveoform, less stringent cut
6 - high frequency part only, flat response
7 - med frequency part only, flat response
8 - low frequency part only, flat response
